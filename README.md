# Stardew Toolkit

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8000`.

Built with plain HTML, CSS, and JavaScript. `styles.css` is the supplied desktop stylesheet; `toolkit.css` applies the Stardew palette, pixel scenery, and responsive layout.

Includes desktop window controls and dragging, seasonal bundle starter checklists, museum and achievement starter checklists, a crop calculator, selected loved gifts, and separate local farm profiles with JSON backup/import. Data saves in browser localStorage. No server account or cloud sync is connected. Checklists are curated subsets; dashboard percentages refer only to included items, not in-game Perfection.
